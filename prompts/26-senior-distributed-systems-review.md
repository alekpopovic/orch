# 26. Senior distributed systems review

```text
Act as a senior distributed systems engineer and review this repository.

Focus areas:
- correctness of scheduler/reconciler separation
- task lifecycle state machine
- rollout safety
- idempotency
- node failure handling
- database transaction boundaries
- API consistency
- security gaps
- observability gaps
- test quality

Output:
1. prioritized findings
2. concrete code changes
3. implementation plan
4. then implement the top critical fixes

Constraints:
- Do not rewrite the entire system.
- Prefer small targeted patches.
- Add tests for every fix.
- Update docs when behavior changes.
```
