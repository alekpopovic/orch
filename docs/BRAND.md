# orch Brand Kit

`orch` uses a bright orbit-and-node identity: a control plane that keeps small Docker clusters moving in sync.

## Logo

The mark is an orbital `o` with three container nodes. It is intentionally compact so it works in the CLI docs, GitHub Pages sidebar, cards, favicon, and release material.

![orch logo mark](assets/orch-mark.svg)

The wordmark pairs the mark with a heavy lowercase `orch` logotype and the `Docker-first orchestration` tagline.

![orch wordmark](assets/orch-wordmark.svg)

## Color System

| Token | Hex | Use |
| --- | --- | --- |
| Orbit Cyan | `#22d3ee` | Highlights, charts, discovery, live signals |
| Control Blue | `#2374e1` | Primary actions, links, active navigation |
| Rollout Violet | `#8b5cf6` | Rollouts, releases, async workflows |
| Success Mint | `#a7f3d0` | Healthy tasks, policy pass, safe states |
| Deep Space | `#020617` | Dark theme background and contrast |
| Slate Text | `#0f172a` | Primary light theme text |

## Visual Language

- 🌈 **Colorful, not noisy:** gradients identify the product, while docs content stays readable.
- 🧭 **Operational:** icons map to real concepts such as scheduling, agents, rollouts, metrics, and security.
- 📈 **Chart-friendly:** architecture and release charts use Mermaid so GitHub and Pages stay source-controlled.
- 🛡️ **Production-shaped:** the dark palette emphasizes operations consoles, alerts, and control-plane status.
